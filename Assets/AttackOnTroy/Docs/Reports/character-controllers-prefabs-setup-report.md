## Controllers

Every controller defaults to Idle. States: player controllers use Idle, Run, Attack, Hurt, Death; Cyclops controllers use Idle, Walk, Throw, Death. `Speed` (float) is present on all controllers; `Attack` (trigger) is on player controllers; `Throw` (trigger) is on Cyclops controllers; `Hurt` (trigger) is on players with Hurt clips; `Die` (trigger) is on all. Any State action/hurt/death transitions are trigger driven; Idle ↔ locomotion uses Speed > 0.01 / Speed <= 0.01. Attack, Throw, and Hurt return to Idle at exit time 1. Death has no outgoing transition and its Any State transition is created first to prioritize it. Any State durations are 0; return duration is 0.05 seconds. Write Defaults is disabled.

## Level 01 actor setup

Menu path: **Attack on Troy > Setup > Configure Level 01 Actors**. It is restricted to active scene `SCN_Level01_Beach`, finds `Actors/PlayerSpawn` and `Actors/CyclopsSpawn`, and creates `Player_Achilles` and `Enemy_CyclopsNormal` under `Actors` using `PrefabUtility.InstantiatePrefab`. It preserves spawn objects and prefab links, skips already-correct instances, uses Undo, marks the active scene dirty, and never saves automatically. Odysseus and Cyclops Heavy are not placed.

## Exact Unity steps

1. Allow Unity to finish importing and compiling scripts.
2. Select **Attack on Troy > Setup > Build Character Controllers and Prefabs** to create/update the four integrated controllers, prefabs, loop flags, and this report.
3. Inspect each prefab in Prefab Mode, especially sprite framing and capsule fit; adjust the Visual scale or collider in the prefab if needed.
4. Open `SCN_Level01_Beach` and make it active.
5. Select **Attack on Troy > Setup > Configure Level 01 Actors**. Review the two instances and save the scene manually only after approval.

## Testing checklist

- [ ] Confirm all listed loop flags; inspect animation keys, sample rates, and sheet import settings remain intact.
- [ ] Verify each controller's default state, parameters, transitions, no duplicate transitions, and no Death exit.
- [ ] Verify prefab root/child transform, initial idle sprite, assigned controller, Rigidbody2D, and single capsule collider.
- [ ] Run Level 01 menu once, inspect hierarchy/prefab connections, run it again to confirm no duplicates, then undo/redo if desired.
- [ ] Confirm no scene auto-save occurred; save manually after review.

## Manual correction

The project does not define an `Actors` sorting layer. Prefabs retain `Default` as a safe sorting layer; add/use an Actors layer and update renderers manually if desired. Collider bounds are estimates derived from imported idle sprite bounds and need visual review for body fit. No terrain physics, gameplay systems, held weapons, or sockets are included.
